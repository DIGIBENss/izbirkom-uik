# Рефлексия

## Что удалось агенту

- Быстро разобрать устройство сайта по минифицированному бандлу: найти базовый URL API,
  эндпоинты, номера отчётов, типы комиссий (`UIK = 5`), имена полей карточки и состава.
- Спроектировать устойчивый парсер: параллельность с паузами, повторы только для временных
  ошибок, сохранение по регионам с продолжением после остановки, атомарная запись файлов.
- Покрыть логику 12 юнит-тестами на заглушке и одним e2e-тестом в настоящем браузере
  на локальном макете.
- E2E-прогон нашёл реальный баг гонки при смене ключа (подробно в `.agent/errors.md`),
  и агент его исправил.

## Что не удалось

- **Проверить на настоящем izbirkom.ru из своей среды (в первой итерации).** В среде агента Chrome получал
  `ERR_BLOCKED_BY_CLIENT` на HTTP-сайтах (izbirkom.ru без HTTPS). Попытку изменить флаги
  браузера классификатор отклонил как обход ограничений среды, и агент её не повторял.
  Поэтому формат ответов API восстановлен по коду фронтенда, а не по живым ответам.
  `normalize.js` написан с запасом: поддерживает `body` и плоский ответ, разные имена полей
  координат, пустые строки.
- **Скриншоты и demo.mp4** не сделаны по той же причине. Их нужно снять после первого
  запуска на своей машине (`docs/screenshots/`).
- **Прямой HTTP-клиент без браузера** (быстрее и легче) не сделан осознанно: он требовал бы
  автоматически решать антибот-проверку сайта.

## Что выяснилось на реальном сайте (вторая итерация)

- `ERR_BLOCKED_BY_CLIENT` воспроизвёлся и у пользователя. Значит, это не ограничение среды
  агента, а режим HTTPS-First в Chrome: izbirkom.ru не отвечает на 443 порту. Исправлено
  флагом `--disable-features=HttpsUpgrades,…` при запуске браузера.
- Предположение о формате было неверным: `/reports/43` для УИК отвечает 404, а карточка
  целиком приходит из `/commissionOrg/{id}`. Агент подсмотрел запросы самой страницы,
  переделал разбор и добавил поля (индекс, населённый пункт, координаты помещения).
- Состав (`/reports/42`) у УИК не публикуется. Запрос стал необязательным (`--members`),
  это вдвое меньше запросов.
- Итог: Адыгея — 265 УИК за минуту, 0 ошибок, адрес и координаты у всех.

## Риски

- В других регионах часть полей может быть не заполнена (как факс в Адыгее).
- Коды субъектов заданы списком. Несуществующие коды просто дают пустой регион.
