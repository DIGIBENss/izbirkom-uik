# izbirkom-uik-parser

CLI-утилита на Node.js: собирает все **участковые избирательные комиссии (УИК)** с сайта
[izbirkom.ru](http://izbirkom.ru/ik) — адрес, телефоны, помещение для голосования,
координаты, срок полномочий — и сохраняет их в JSON.

**Тип проекта:** инструмент автоматизации (парсер / CLI-утилита).

## Почему именно так

izbirkom.ru — одностраничное приложение (Vue). Данные о комиссиях оно берёт из API
`apps.cikrf.ru/service/ik-inp-service-pbcopy`, который без заголовка `X-Api-Key` отвечает
`401`. Ключ страница получает сама, пройдя проверку браузера (JS-challenge).

Парсер **не обходит** эту проверку. Он запускает настоящий браузер (Chrome/Edge через
Playwright), открывает страницу «Избирательные комиссии» и ждёт, пока код сайта сам
получит ключ. Затем делает запросы к API из той же страницы — так же, как сайт. Когда
ключ истекает, страница перезагружается и сайт выдаёт новый.

**Обоснование применимости:** на сайте нет выгрузки всех УИК одним файлом, а вручную
просматривать около 95 тысяч карточек нереально. Парсер выгружает данные в машиночитаемом
виде: для аналитики, карт, проверки адресов участков.

## Стек

- Node.js ≥ 18 (ESM, встроенные `fetch` и `node:test`)
- [playwright-core](https://playwright.dev) + установленный Google Chrome или Microsoft Edge
  (браузер не скачивается)

## Установка и запуск

```powershell
npm install
```

Один регион для пробы (Адыгея):

```powershell
node src/main.js --regions 01
```

Вся страна:

```powershell
node src/main.js
```

| Опция | По умолчанию | Описание |
|---|---|---|
| `--regions 01,77,78` | все | коды субъектов РФ |
| `--out data/uik.json` | `data/uik.json` | итоговый файл |
| `--concurrency N` | `2` | параллельных запросов (1–4) |
| `--delay MS` | `300` | пауза между запросами одного потока |
| `--members` | — | дополнительно запрашивать состав комиссии (для УИК ЦИК его обычно не публикует) |
| `--fresh` | — | скачать заново уже готовые регионы |
| `--headful` | — | показать окно браузера (для отладки) |
| `--channel` | `chrome` | `chrome`, `msedge` или `chromium` (после `npx playwright install chromium`) |

Каждый регион сохраняется сразу после скачивания в `data/regions/XX.json`. Если запуск
прервать (Ctrl+C), повторный запуск пропустит готовые регионы. В конце все регионы
собираются в `data/uik.json`.

Полная выгрузка — это около 95 тысяч запросов (одна карточка на УИК). Адыгея (265 УИК)
скачивается примерно за минуту, вся страна при настройках по умолчанию — несколько часов. Не повышайте нагрузку на сервер ЦИК
без необходимости.

```json

  "generatedAt": "2026-11-22T12:00:00.000Z",
  "total": 3,
  "regions": [{ "subjectRfCode": "01", "name": "Центральная избирательная комиссия Республики Адыгея", "uikCount": 3, "errors": 0 }],
  "uiks": [
    {
      "id": "…",
      "numericId": 452989253,
      "number": "1",
      "name": "Участковая избирательная комиссия №1",
      "subjectRfCode": "01",
      "region": "Центральная избирательная комиссия Республики Адыгея",
      "tik": { "id": "…", "type": "ТИК", "name": "Майкопская городская ТИК" },
      "address": "385600, Республика Адыгея, Гиагинский район, станица Гиагинская, …",
      "postCode": "385600",
      "locality": "Республика Адыгея, Гиагинский район, станица Гиагинская",
      "phone": "8(8772)…",
      "fax": null,
      "votingRoom": { "address": "…", "phone": "…", "postCode": "…", "locality": "…", "geo": { "lat": 44.88, "lon": 40.04 }, "description": null },
      "geo": { "lat": 44.6098, "lon": 40.1006 },
      "termEndDate": "2028-06-01",
      "extendedUntil": null,
      "path": [{ "id": "…", "type": "ИКСРФ", "name": "…" }, { "id": "…", "type": "ТИК", "name": "…" }],
```

Пустые поля записываются как `null`. Если отчёт по комиссии не пришёл, запись всё равно
сохраняется, а ошибка попадает в `errors` файла региона. Поле `members` появляется только
с флагом `--members`.

## Структура

```
src/
  main.js                 точка входа (CLI)
  services/browser.js     браузерная сессия: получение ключа, запросы к API
  services/izbirkomApi.js эндпоинты API, повторы при сбоях
  services/scraper.js     обход дерева комиссий и сбор УИК по региону
  services/storage.js     сохранение по регионам и сборка итогового JSON
  utils/tree.js           работа с деревом комиссий
  utils/normalize.js      приведение ответов API к итоговой записи
  utils/limiter.js        пул параллельных запросов, retry
  utils/args.js           разбор аргументов CLI
tests/                    юнит- и e2e-тесты, фикстуры, макет сервера
docs/architecture.md      схема компонентов
.agent/                   артефакты работы с ИИ-агентом
```

Папок `components/` и `styles/` из примерной структуры нет: это CLI без интерфейса.

## Ограничения

- Проверено на реальном сайте на Адыгее (265 УИК, 0 ошибок). Факс и продление полномочий
  там пустые: ЦИК их не заполняет.
- izbirkom.ru работает только по HTTP. Поэтому парсер запускает Chrome с отключённым
  режимом HTTPS-First, иначе Chrome обрывает загрузку с `ERR_BLOCKED_BY_CLIENT`.
- Если ЦИК изменит API или проверку, парсер придётся обновить.
