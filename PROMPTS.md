# Дневник промптов

Агент: Claude Code (модель Claude Opus 5.5), десктоп-приложение, режим auto.

## 1. Постановка задачи

> http://izbirkom.ru/ — нужно написать парсер на node js, забрать все УИК с данными и
> сохранить всё в JSON. *(+ скриншот примерной структуры проекта)*

**Что сделал агент:** изучил сайт. Выяснил, что это SPA, а данные идут из API
`apps.cikrf.ru`. Нашёл в бандле `app.js` эндпоинты (`/commissionOrg`, `/reports/42`,
`/reports/43`) и антибот-проверку (`/challenge/get` → `/challenge/solve` → `X-Api-Key`).
Попытку решать проверку скриптом заблокировал классификатор безопасности. Агент остановился
и предложил три варианта.

**Вывод:** короткий промпт без контекста сработал, потому что агент сам провёл разведку.
Но решение «как обходить защиту» он правильно оставил человеку.

## 2. Выбор подхода

> Через браузер

**Что сделал агент:** выбрал Playwright с системным Chrome, чтобы не скачивать браузер.
Сайт сам проходит проверку, парсер только переиспользует ключ страницы. Запустить реальный
сайт в браузере из среды агента не удалось: HTTP-сайты там заблокированы. Поэтому агент
сделал локальный макет сайта и API со сменой ключа и проверил на нём всю цепочку.

**Вывод:** односложный ответ на вопрос с вариантами — хороший способ управлять агентом.
Подробности он додумывает сам, но об ограничениях среды нужно спрашивать явно.

## 3. Обратная связь от реального запуска

> *(вставлен вывод запуска)* `Ошибка: page.goto: net::ERR_BLOCKED_BY_CLIENT at http://izbirkom.ru/ik?subjectRfCode=01`

**Что сделал агент:** по тому, что ошибка повторилась у пользователя, понял, что причина
не в песочнице, а в режиме HTTPS-First в Chrome, и исправил её флагом запуска. Затем
прогнал Адыгею и увидел пустые карточки. Записал запросы живой страницы, нашёл
правильный эндпоинт (`/commissionOrg/{id}`) и переделал разбор: 265 УИК, 0 ошибок.

**Вывод:** вставить точный вывод ошибки — лучший промпт для отладки. Одна строка лога
дала агенту ключевую подсказку.

## Что можно было сформулировать лучше

- Сразу указать нужные поля (нужен ли состав комиссии, координаты), регион для пробы и
  допустимую нагрузку на сервер.
- Указать, где запускать проект, чтобы агент не работал во временной папке.
